# 提示词库架构

状态：当前

## 定义

提示词库是后端合并后的、带修订版本的只读视图。提示词来源是可配置的上游或内置来源；Studio 消费库中的条目，设置页管理来源和刷新动作。

## 数据流

```text
内置来源 / 远程来源
        -> PromptLibraryService 校验、规范化、缓存
        -> PromptLibraryView
        -> /api/prompts 与管理端来源接口
        -> Studio / Settings 渲染
```

`PromptLibraryView` 是严格契约，包含生成时间、内容 revision、来源 revision、来源统计、错误摘要、条目和来源列表。计数字段由后端校验，前端不重新合并或重新统计来源。

## 运行规则

- `GET /api/prompts` 为 Studio 和设置页提供统一库视图，管理端路由只负责刷新与更新来源。
- 服务对远程 URL、路径、清单大小和下载大小做边界校验，并将成功快照与来源错误分开记录。
- 单个来源失败不应清空已有可用缓存；前端展示后端给出的来源状态和错误摘要。
- 条目 ID、提示词正文和 revision 由后端决定。Studio 只把选中的提示词写入本地输入草稿或任务请求。

新增提示词来源时，应先扩展来源契约和服务端规范化逻辑，再让前端显示新字段；不要在 Studio 中直接拉取或解析第三方来源。
